# The World in One Page, 20 November 2026

A deterministic Python and TypeScript entry that draws one 1024x1024 image summing up the world news of Friday 20 November 2026, with the day's 30 leading stories rendered as a dense newspaper front page complete with flat geometric illustrations, key figures, regional counts, and a story locator map.
